# street-retail-aggregator
Система предназначена для объединения владельцев коммерческих помещений на первых этажах и предпринимателей. Главная особенность проекта — **интеллектуальный алгоритм рекомендаций**, который анализирует инфраструктуру локации и наличие прямых конкурентов (других ПВЗ или кофеен) в здании, помогая бизнесу выбрать оптимальное место для открытия.
