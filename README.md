# 🏙️ Street Retail Aggregator

Корпоративная информационная система (КИС) для поиска, аренды и сдачи коммерческой недвижимости формата «стрит-ритейл» с умной рекомендательной системой на основе геоданных.

## 🚀 Быстрый старт

### С Docker (если применимо)

```bash
# Запуск базы данных и бэкенда
docker-compose up -d

# Запуск фронтенда
cd frontend
flutter run
```

## 🎯 Возможности

### 🏢 Для Арендатора (Бизнеса)
- 🗺️ **Интерактивная карта** - Поиск доступных помещений с визуализацией на карте (Yandex MapKit).
- 🧠 **Умное ранжирование** - Подсветка наиболее перспективных точек с учетом профиля бизнеса арендатора и отсутствия прямых конкурентов поблизости.
- 🔍 **Продвинутая фильтрация** - Поиск по критичным параметрам (выделенная электрическая мощность (кВт), наличие мокрых точек, вытяжки, отдельного входа).
- 📨 **Управление заявками** - Отправка откликов арендодателям и отслеживание статусов заявок в реальном времени.

### 🔑 Для Арендодателя
- 📋 **Управление объектами (CRUD)** - Создание и редактирование карточек помещений с подробными техническими характеристиками.
- 📍 **Картирование соседей** - Указание действующих бизнесов в здании для интеграции с рекомендательным ядром системы.
- 💬 **Обработка откликов** - Взаимодействие с потенциальными арендаторами через защищенный личный кабинет.

## Стек

- **Backend Framework**: Java, Spring Boot
- **Security**: Spring Security (JWT-авторизация, Role-Based Access Control @PreAuthorize, BCrypt для паролей)
- **Database**: PostgreSQL
- **Frontend Framework**: Flutter
- **Mapping / GIS**: Интеграция с Yandex MapKit
- **Architecture**: REST API

## 🤖 Рекомендательная система

Основа платформы — модуль пространственного анализа. При поиске помещения под конкретную категорию бизнеса (например, «ПВЗ Ozon»), алгоритм проверяет связи в базе данных на наличие аналогичных категорий в выбранном здании. При совпадении (наличие конкурента) приоритет объекта в выдаче динамически снижается, что защищает арендатора от каннибализации трафика и помогает найти свободные ниши.
