# 🏙️ Street Retail Aggregator

Корпоративная информационная система (КИС) для поиска, аренды и сдачи коммерческой недвижимости формата «стрит-ритейл» с умной рекомендательной системой на основе геоданных.

## 🚀 Быстрый старт

### С Docker (если применимо)

```bash
# Запуск базы данных и бэкенда
docker-compose up -d

# Запуск фронтенда
cd frontend
flutter run
```

## 🎯 Возможности

### 🏢 Для Арендатора (Бизнеса)
- 🗺️ **Интерактивная карта** - Поиск доступных помещений с визуализацией на карте (Yandex MapKit).
- 🧠 **Умное ранжирование** - Подсветка наиболее перспективных точек с учетом профиля бизнеса арендатора и отсутствия прямых конкурентов поблизости.
- 🔍 **Продвинутая фильтрация** - Поиск по критичным параметрам (электрическая мощность, мокрые точки, вытяжка, отдельный вход).
- 📨 **Управление заявками** - Отправка откликов, отслеживание статусов и возможность удаления истории заявок (свайпом).
- ⭐️ **Избранное** - Сохранение понравившихся объектов с уведомлением об изменении их статуса (например, если объект снят с публикации).

### 🔑 Для Арендодателя
- 📋 **Управление объектами (CRUD)** - Полный цикл управления карточками помещений и их статусами (Опубликовано / Снято).
- 📈 **Аналитика** - Дашборд с показателями просмотров, добавлений в избранное и конверсии в заявки.
- 💬 **Коммуникация** - Прямой чат с потенциальными арендаторами прямо из списка входящих заявок.
- 📨 **Обработка откликов** - Принятие или отклонение заявок с указанием причины, а также возможность удаления неактуальных заявок.

## Стек

- **Backend Framework**: Java 17+, Spring Boot 3
- **Security**: Spring Security (JWT, RBAC, BCrypt)
- **Messaging**: WebSocket (STOMP) для чатов в реальном времени
- **Notifications**: Система Push-уведомлений о статусах заявок
- **Database**: PostgreSQL
- **Frontend Framework**: Flutter (Dart)
- **Mapping / GIS**: Yandex MapKit SDK

## 🤖 Рекомендательная система

Основа платформы — модуль пространственного анализа. При поиске помещения под конкретную категорию бизнеса (например, «ПВЗ Ozon»), алгоритм проверяет связи в базе данных на наличие аналогичных категорий в выбранном здании. При совпадении (наличие конкурента) приоритет объекта в выдаче динамически снижается. Система также учитывает технические требования бизнеса (например, наличие вытяжки для общепита).
